# Mini STL

A project to learn the internals of the C++ Standard Template Library by implementing common containers from scratch.

## Current Progress

### Vector<T>

Implemented:

- Dynamic contiguous storage
- push_back()
- pop_back()
- reserve()
- resize()
- operator[]
- size()
- capacity()
- empty()

## Upcoming

- Rule of Five
- Iterators
- Placement new
- Exception safety
- Allocators
- List
- Deque
- Map
- Unordered Map

## Goal

Understand how the STL works internally instead of only using it.
